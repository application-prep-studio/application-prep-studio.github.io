# Application Prep Studio

Application Prep Studio is a private, browser-based workspace for:

- tailoring a résumé to a job posting without inventing experience;
- finding relevant ATS keywords and adding only supportable language;
- exporting polished résumé files; and
- preparing for role-specific interviews.

Résumé processing happens in the browser. A small public helper is used only
when a user chooses to import a job posting from a link.

## Publishing

GitHub Actions builds this project and publishes it to GitHub Pages whenever
the `main` branch changes.
